# AI Module Documentation

## Overview
The AI Module provides a basic chatbot functionality using the Google Gemini API. It allows authenticated users to interact with the AI and records their chat history.

## Architecture
The module follows Clean Architecture principles:
- **Domain**: Contains the `ChatHistory` entity and repository interfaces.
- **Application**: Contains the `AIService` logic, DTOs, and interface definitions.
- **Infrastructure**: Contains the `AIDbContext`, `AIRepository` implementation, and `GeminiService` for external API communication.
- **API**: Contains the `AIController` for exposing endpoints.

## Database Design
The module uses a dedicated schema `ai` within the main database.

### Entity: ChatHistory
Table: `ai.chat_history`

| Column Name | Type | Key | Description |
| :--- | :--- | :--- | :--- |
| `Id` | UUID | PK | Unique identifier for the chat interaction |
| `UserId` | UUID | | The ID of the authenticated user (Foreign Key logic from Identity) |
| `UserPrompt` | Text | | The message sent by the user |
| `AIResponse` | Text | | The response generated by the AI |
| `CreatedAt` | Timestamp | | Timestamp of the interaction |

## API Endpoints
All endpoints require Authentication (Bearer Token).

### 1. Ask AI
Sends a prompt to the AI and gets a response. Saves the interaction to history.

- **URL**: `/api/ai/ask`
- **Method**: `POST`
- **Auth**: Required
- **Request Body**:
  ```json
  {
    "prompt": "What is clean architecture?"
  }
  ```
- **Response**:
  ```json
  {
    "response": "Clean architecture is..."
  }
  ```

### 2. Get Chat History
Retrieves the chat history for the current authenticated user.

- **URL**: `/api/ai/history`
- **Method**: `GET`
- **Auth**: Required
- **Response**:
  ```json
  [
    {
      "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
      "prompt": "Hello",
      "response": "Hi there!",
      "createdAt": "2024-01-01T12:00:00Z"
    }
  ]
  ```

### 3. Delete Chat Entry
Deletes a specific chat history entry.

- **URL**: `/api/ai/history/{id}`
- **Method**: `DELETE`
- **Auth**: Required
- **URL Parameters**:
    - `id`: UUID of the chat history entry.
- **Response**: `204 No Content`

## Configuration
The application requires the following configuration in `appsettings.json` or Environment Variables:

```json
{
  "Gemini": {
    "ApiKey": "YOUR_GOOGLE_GEMINI_API_KEY"
  }
}
```
